Put each place's photos and videos in its own folder here, for example:

  media/Kolkata/howrah-bridge.jpg
  media/Kerala/houseboat.mp4
  media/Bangalore/cubbon-park.jpg

Folder names can be the place name or a common spelling (Calcutta, Bengaluru,
Kashimir, Gujurat, New Delhi...). Subfolders are fine.
Works with: jpg, jpeg, png, webp, gif, avif, mp4, webm, mov, m4v.
iPhone HEIC photos need converting to JPG first.
The file name becomes the caption ("howrah-bridge.jpg" → "howrah bridge").
